# Level Up

Una quest al giorno: streak, livelli, boss e un buddy che cresce con te.
App web installabile (iPhone: Safari → Condividi → Aggiungi alla schermata Home).

- Tutto resta nel browser o nell'app di chi gioca: la pagina non manda dati a nessuno.
- Nessun account, nessuna pubblicità, niente acquisti.
- Idee prese da «Atomic Habits» di James Clear.
